# Triage labels — PROMueve Nexus

Matt skills use five canonical triage roles. The repository currently exposes some, not all, of those labels. Do not create or rename labels as a side effect of ordinary implementation.

| Matt role | Tracker label | Current note |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | create/use only when an explicitly authorized triage workflow needs it |
| `needs-info` | `needs-info` | create/use only when an explicitly authorized triage workflow needs it |
| `ready-for-agent` | `ready-for-agent` | already present |
| `ready-for-human` | `ready-for-human` | create/use only when an explicitly authorized triage workflow needs it |
| `wontfix` | `wontfix` | already present |

`status:approved` is a separate PROMueve governance label. It is not equivalent to `ready-for-agent` and remains required by repository publication rules when opening a PR.
