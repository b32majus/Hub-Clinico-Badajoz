### WHAT / ACEPTACIÓN OBSERVABLE Y FALSABLE
1. Con Excel sintético real y paciente SYN-DASH-D4 que contiene FR como número 2, Dashboard termina de cargar sin pageerror/console.error atribuible al bug, permanece visible, #biomarkerFr no se traduce a un resultado clínico, muestra fielmente el valor explícito como texto y conserva la clase neutral/unknown.
2. El token numérico 0 no se equipara silenciosamente a ausencia. El cero explícito se representa literalmente y neutral; null, undefined o string vacío conservan el estado de dato ausente No analizado. No inferir estados positivo/negativo a partir de 0/1/2 ni de nombre del biomarcador.
3. Tokens textuales Positivo/Negativo conservan su representación y clase; token textual no reconocido permanece neutral sin inventar veredicto. Sin cambios en cálculos, unidades, scores, umbrales o reglas clínicas.
4. Con ese registro numérico, cabecera y datos generales, KPIs, biomarcadores, resumen clínico, tratamiento, histórico, eventos y región de gráficas/tabla siguen accesibles; cuando no hay dos visitas se mantiene el estado vacío explicativo de los gráficos, no una curva inventada. No ocultar pantalla ni recuperar con paciente demo falso.
5. El profesional puede pulsar el control real Solicitud FH y obtener texto no vacío, con identidad, diagnóstico, contenido clínico explícito y estados prebiológicos existentes; mantener el blacklist legacy y sin afirmar validado, START/SWITCH/ADD_ON. Los controles de Seguimiento y exportación de visitas quedan conectados/operables para la siguiente acción.
6. Pacientes normales de D1/D2/D3, sin biomarcador numérico, mantienen exactamente sus pruebas existentes. Errores/no encontrado/ausencia y flujo de importación no se modifican. Sin añadir persistencia ni exportación estructurada.
