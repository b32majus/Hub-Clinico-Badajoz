# Farmacia — Importación local Excel Enfermería/Farmacia

Fecha: 2026-06-12
Status: pending_review

## Decisión funcional

- CIMA se carga automáticamente como catálogo de referencia.
- Excel Enfermería y Excel Farmacia se cargan manualmente por botón.
- En demo estática no hay backend ni persistencia real.
- Los datos cargados son locales del navegador.

## Botones

- Cargar Excel de Enfermería
- Cargar Excel de Farmacia

## CIMA

- Sin botón manual.
- Estado automático.
- Pendiente integración real si no hay dataset oficial.

## Limitaciones

- Demo/formativo.
- No datos reales.
- No persistencia servidor.
- No uso clínico.
