# Farmacia v0.4 — Backlog de neoplasias

Fecha: 2026-06-11
Estado: backlog clínico pendiente
Decisión actual: no implementar en esta WO

## 1. Petición registrada

Tras reunión con Jefatura de Servicio de Farmacia Hospitalaria de Cáceres se solicita seguimiento específico de neoplasias en pacientes con biológicos.

## 2. Decisión de alcance

No se implementa en v0.4 de esta sesión.

Motivo:

- falta definición clínica y funcional suficiente;
- su impacto puede afectar modelo longitudinal, farmacovigilancia y salidas del dashboard;
- no es seguro introducirlo dentro de un prototipo acotado sin cerrar primero el modelo multibiológico y de EA.

## 3. Preguntas clínicas pendientes

- qué neoplasias deben registrarse;
- qué variables mínimas son obligatorias;
- qué periodicidad de seguimiento se espera;
- qué relación exacta debe registrarse con el biológico;
- qué salida necesita el servicio;
- si el objetivo es farmacovigilancia, cribado, seguimiento o investigación.

## 4. Riesgos si se implementa sin definición

- mezclar farmacovigilancia con comorbilidad oncológica sin criterio estable;
- generar variables irrelevantes o incompletas;
- romper trazabilidad longitudinal;
- introducir salidas ambiguas para auditoría clínica.

## 5. Recomendación para siguiente WO

Abrir WO clínica específica de neoplasias con:

- casos de uso;
- campos mínimos;
- reglas temporales;
- relación con línea biológica;
- necesidades de dashboard, exportación y explotación estadística.
